# keyring 쇼핑몰
- `index.html`을 브라우저에서 열면 실행됩니다.
- GitHub 저장소 최상위(root)에 `index.html`, `style.css`, `script.js`, `img/`를 함께 올리세요.
- GitHub 저장소 Settings > Pages > Deploy from a branch > main / root를 선택하고 Save를 누르세요.
- 회원·장바구니·주문은 현재 브라우저의 localStorage에 저장되는 수업용 데모입니다.
- 로그인 비밀번호는 데모 편의를 위해 브라우저에 저장되므로 실제 서비스에 사용하면 안 됩니다.
